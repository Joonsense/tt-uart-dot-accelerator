## How it works

A UART (8N1, 8 clocks per bit) accelerator that receives two signed INT8 vectors (N=8), computes their dot product and sends the result back over UART. All products are summed exactly, then a single 20-bit saturate is applied to the final result.

Design `3c0e790e-9bc7-4b0f-ac17-f176d263fcc5` was verified in chip-lab against a fixed reference model and an RTL scoreboard, then wrapped for the Tiny Tapeout pinout.
Pre-layout sky130 standard cell area is 6506 um^2 and the selected tile size is 1x1 (estimate).

## How to test

Baud rate = clock / 8. For 115200 baud set the project clock to 921,600 Hz (the default 10,000,000 Hz gives 1,250,000 baud).

Use the demo board RP2040 serial port (ui_in[3]=RX, uo_out[4]=TX). Send the 16 bytes a0,b0,...,a7,b7 (two's complement); the 3-byte result comes back least significant byte first, sign extended.

uo_out[0] is BUSY, uo_out[1] flags a framing error (stop bit 0), uo_out[7:5] counts completed vectors (mod 8).
